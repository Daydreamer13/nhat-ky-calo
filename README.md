# Nhật Ký Calo

App chụp ảnh bữa ăn để tính calo, cộng dồn theo ngày so với mục tiêu giảm cân, kèm cây hoa, chuỗi ngày,
huy hiệu, lời nhắn và quà theo mốc để giữ động lực.

- **Mở app:** https://daydreamer13.github.io/nhat-ky-calo/
- **Hướng dẫn cài đặt và thiết lập:** [HUONG-DAN.md](HUONG-DAN.md)

App là một trang web cài được lên màn hình chính điện thoại (PWA): các file tĩnh, không cần build, mở được cả
khi mất mạng. Dữ liệu và khoá Claude chỉ nằm trên máy người dùng, không nằm trong kho này.

Thực hiện: Dreamer.
